TodoUp Flutter is a modern mobile productivity application designed to help users manage tasks, stay organized, and receive reminders with a smooth and polished experience. The project is structured to support future growth, better maintenance, and easier collaboration.

## Why This Project Matters

- Productivity-focused mobile app experience
- Clean Flutter architecture for scalable development
- Supabase-powered sync and backend support
- Reminder and user engagement features
- Strong foundation for future app enhancements

## Requirements

- Flutter SDK 3.8 or newer
- Dart SDK compatible with Flutter
- Android Studio / VS Code with Flutter extensions
- Supabase project credentials for backend features

## Running the App

```bash
cd app
flutter pub get
flutter run
```

### Optional build commands

```bash
flutter build apk --release
flutter build appbundle --release
```

## Getting Started

1. Clone the repository
2. Open the app folder in your editor
3. Install dependencies with flutter pub get
4. Run the app on an emulator or physical device
5. Configure backend credentials if Supabase features are required
